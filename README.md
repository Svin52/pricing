## Трекер задач

Задачи живут в Issues, а таблица ниже обновляется автоматически.
Создать задачу: «➕ Новая задача». Выполнить: закрыть issue кнопкой **Close issue** (она уйдёт в историю).
Удалить: закрыть как **Close as not planned** или удалить issue (из трекера пропадёт совсем).
