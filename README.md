# Стратегия ценообразования на авиабилеты

Студенческий проект.

## Трекер задач

В папке [`docs/`](docs/index.html) лежит простой трекер задач проекта, который открывается как сайт через GitHub Pages:
создание задач с дедлайнами, отметка «выполнено» (задача уходит в историю), удаление (задача исчезает).

**Как включить:** Settings → Pages → Build and deployment → Source: «Deploy from a branch»,
выбрать ветку `main` и папку `/docs`, нажать Save. Через минуту сайт будет по адресу
`https://svin52.github.io/pricing/`.

**Где хранятся задачи.** По умолчанию в браузере (localStorage), то есть только на том устройстве, где их создали.
Чтобы видеть задачи с любого устройства, раскройте блок «Синхронизация через GitHub» внизу страницы и вставьте
fine-grained токен (Settings → Developer settings → Personal access tokens → Fine-grained tokens,
доступ только к этому репозиторию, право Contents: Read and write). Задачи будут сохраняться в `tasks/tasks.json`.
