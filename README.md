## Трекер задач

Задачи живут в Issues, а таблица ниже обновляется автоматически.
Создать задачу: «➕ Новая задача» (там есть поле для дедлайна) или обычный New issue, написав дату в начале названия, например `14-11-2026 сделать презентацию` (подходят и `14.11.2026`, `2026-11-14`, `14.11`, можно со временем `14.11 18:00`). Выполнить: закрыть issue кнопкой **Close issue** (она уйдёт в историю).
Исполнитель берётся из Assignees или из поля «Исполнитель» в форме, «Назначил» — автор задачи. Удалить: закрыть как **Close as not planned** или удалить issue (из трекера пропадёт совсем).
